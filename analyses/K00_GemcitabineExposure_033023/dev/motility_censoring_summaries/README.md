# Motility Summaries With Censoring Stress Checks

Prototype analysis for comparing 2N and 4N motility among accepted yellow
trajectories without treating censoring correction as the main identifying
assumption.

Run from the repository root:

```bash
scripts/agentRrunner.sh analyses/K00_GemcitabineExposure_033023/dev/motility_censoring_summaries/scripts/01_motility_censoring_summaries.R
```

Useful options:

```bash
--max_lag=5
--acf_lag=2
--fixed_window=5
--max_censor_rows=250000
--max_ipcw_weight=20
--censoring_model_rds=analyses/K00_GemcitabineExposure_033023/dev/censoring_audit/artifacts/censoring_models.rds
--out_dir=analyses/K00_GemcitabineExposure_033023/dev/motility_censoring_summaries/results
```

The censoring model is loaded from the censoring-audit artifact at
`dev/censoring_audit/artifacts/censoring_models.rds`. This file must exist and
should be regenerated by the censoring audit workflow before running this
prototype. `--max_censor_rows` only controls how many at-risk rows are sampled
for holdout model-quality plots and the IPCW stabilizing numerator model; it
does not refit the denominator censoring model.
IPCW weights are capped at the smaller of the requested percentile cap and
`--max_ipcw_weight`, because the raw dropout process can produce extremely small
estimated survival probabilities.

Interpretation should stay deliberately modest: Layer 1 describes observed
accepted yellow trajectories, Layer 2 checks whether observation is informative,
and Layer 3 asks whether the 4N-vs-2N direction survives a short-lag IPCW stress
check with hard 95th and 99th percentile weight caps.
